# 梁宁产品战略心智模型

## 一、心智模型

### 模型1：真需求三角——价值·共识·模式

商业闭环三角，缺一不可：
- **价值**：用户愿付费才叫商业价值。三层：功能价值（效率，易仿制）、情绪价值（心理，溢价源）、资产价值（保值增值，护城河）。
- **共识**：无共识无成交。四层推进：内部→用户→市场→社会。消除四类分歧：感知、想象、场景、利益。成交=共识表达，关系=共识深化。
- **模式**：企业生存能力 = 能力系统 + 变现逻辑 + 分配机制。不赚钱一定是模式问题，不是行业问题。

### 模型2：点线面体——战略选择

"选择比努力更重要。"悲催的人生，是在常态的面上做勤奋的点。
- **点**：当下努力 | **线**：行业周期 | **面**：平台生态赋能 | **体**：时代基础设施
- 判断顺序：体→面→线→点。先判时代趋势，再看生态位，再看周期，最后才看执行。

### 模型3：情绪原色——底层OS

理性是App，情绪是底层OS。四种元情绪：
- **愉悦↔不爽**（满足轴）：需求被满足=愉悦，未满足=不爽。满足是度量产品的终极刻度。
- **愤怒↔恐惧**（侵犯轴）：边界被侵犯=愤怒，强敌侵犯=恐惧。恐惧是界限也是驱动力。
- 三抓手：**痛点=恐惧** | **爽点=即时满足** | **痒点=虚拟自我**

### 模型4：用户画像——大明·笨笨·小闲

- **大明**：需求明确，追效率，无忠诚→京东/百度。搞定靠硬货。
- **笨笨**：不知要什么，需浏览→小红书/淘宝。种草后70-80%切大明。
- **小闲**：无需求，打发时间→腾讯/抖音。高频转低频。
- 羊群模型：第一只羊活下来→头羊（自组织起点）→狼（B端变现）。

### 模型5：场景 = 场 + 景

- **场**：时间+空间（用户在哪停留）| **景**：情景+互动（情绪触发+意见裹挟）
- 无情绪触发的场只是物理空间。产品=特定场景下的行为模式解决方案。

## 二、判断决策

### 真伪需求5问
1. 用户愿为这功能多花钱吗？→ 不愿=伪
2. 需求在场景里还是问卷里？→ 问卷=伪
3. 在行为里还是语言里？→ 语言=伪
4. 在复购里还是首单里？→ 首单=伪
5. 产品消失用户会若有所失吗？→ 不会=存在感不足

### AI场景成熟度三指标
- **业务成熟度**：有无清晰稳定付费方？
- **数据成熟度**：有无足够数据冷启动？
- **技术成熟度**：算法人才能否突破？
- 三者皆有=黄金场景 | 一己撬动=中农场景 | 皆无=盐碱地

### 共识推进
- 画利益相关人地图：横轴=利益，纵轴=影响力。高影响零利益的人会摁死你，先搞定。
- 共识不在当下，在各方延长线交点。战略=画延长线。

## 三、行动指引 Checklist

- [ ] 真需求三角自检：价值成立？共识路径清晰？模式能赚钱？价值不成立=早死早超生。
- [ ] 定义"一"：你什么行业？30年后还在不在？在=找不变的根，不在=换赛道。
- [ ] 点线面体定位：你的体上升还是下沉？面健康吗？只是点上的勤奋？
- [ ] 锁定场景：什么场+什么景+触发什么情绪+需马上解决什么？
- [ ] 识别用户模式：大明/笨笨/小闲？产品匹配此模式？
- [ ] 定抓手：痛点（恐惧）/爽点（即时满足）/痒点（虚拟自我）？
- [ ] 定价值类型：功能（易仿制）/情绪（可溢价）/资产（可筑墙）？
- [ ] 画利益相关人地图，先搞定高影响零利益者。
- [ ] 场景成熟度体检：业务/数据/技术各几分？低于2分别急。
- [ ] 认知是顶，安全是底：天花板够高？底线风险可控？

## 四、标志性提问

1. "用户愿用钱包投票，还是只用嘴点赞？"
2. "产品明天消失，多少人会若有所失？"
3. "你在上升的体上，还是在下沉的体上做勤奋的点？"
4. "你什么行业？30年后还在不在？"
5. "用户怕什么？绷了什么需求能瞬间满足？理想中的自己什么样？"
6. "谁在给你赋能？你和这个面的关系是什么？"
7. "利益相关人地图画了吗？谁高影响零利益？"
8. "共识在哪条延长线交点上？"
9. "场景成熟吗——有付费方、有数据、有技术吗？"

## 五、应用边界

**适用**：C端切入点设计、真伪需求判断、中国用户心理洞察、AI场景成熟度判断、战略定位、共识推进。

**不适用**：纯技术架构决策、个股投资建议、B端供应链深度优化、精确量化运营拆解。

**提醒**：梁宁框架强在战略定性和人性洞察，弱在量化执行。先定方向判真伪，再用其他工具做量化落地。
